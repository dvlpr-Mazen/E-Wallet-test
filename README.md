# 💳 محفظتي الذكية | Smart E-Wallet (Single Page Application)

تطبيق **محفظة إلكترونية مبسطة وتفاعلية بالكامل في صفحة واحدة (Single Page Web App)** بتصميم عصري مستوحى من أحدث تطبيقات التقنية المالية (FinTech) مثل Apple Wallet و STC Pay و Revolut.

---

## ✨ المميزات الرئيسية

1. **الواجهة والتصميم العصري (Modern FinTech UI)**:
   - دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (`dir="rtl"`).
   - نمط زجاجي ناعم (Glassmorphism) مع ألوان ليلية متناسقة.
   - بطاقة بنكية افتراضية بلاتينية بمؤثرات انعكاس ضوئي (Card Shimmer).
   - إمكانية **تجميد / إلغاء تجميد البطاقة** بنقرة زر لحمايتها.
   - زر نسخ رقم البطاقة وإخفاء/إظهار تفاصيل الرصيد للخصوصية.

2. **العمليات المالية الأساسية**:
   - 💸 **إرسال وتحويل أموال**: تحويل فوري لأي شخص مع تصنيف المعاملة وفحص كفاية الرصيد.
   - ⚡ **التحويل السريع لجهات الاتصال**: جهات اتصال مفضلة بألوان رمزية، مع إمكانية إضافة جهات جديدة.
   - ➕ **شحن رصيد المحفظة (Deposit)**: عبر بطاقة مدى/ائتمان، Apple Pay، أو تحويل IBAN مع أزرار مبالغ سريعة.
   - 🧾 **سداد الفواتير (Bills Payment)**: سداد فواتير الكهرباء، الاتصالات والإنترنت، والمياه مع حفظ رقم المشترك.
   - 📲 **رمز الـ QR Code**: مشاركة كود الاستقبال السريع ومعرف المحفظة الرقمية.

3. **لوحة تحليلات ورسوم بيانية ذكية (Spending Analytics)**:
   - رسم بياني تفاعلي (Doughnut Chart عبر Chart.js) يوضح توزيع النفقات حسب الفئات (تسوق، فواتير، تحويلات...).
   - يتحدث الرسم البياني تلقائياً لحظة إجراء أي عملية جديدة.

4. **سجل المعاملات والإيصالات (Transaction History & Receipts)**:
   - فلترة المعاملات: (الكل / الوارد / الصادر / الفواتير).
   - بحث فوري بالاسم أو نوع المعاملة أو المبلغ.
   - **إيصال رقمي تفصيلي**: الضغط على أي معاملة يفتح إيصالاً إلكترونياً قابلاً للطباعة أو المشاركة.
   - إمكانية **تصدير السجل بالكامل بصيغة CSV (Excel)** بترميز UTF-8 يدعم العربية بشكل كامل.

5. **تجربة مستخدم تفاعلية (Micro-Interactions)**:
   - مؤثرات احتفالية (Confetti) عند نجاح العمليات.
   - نغمة تنبيه صوتية لطيفة (Fintech Sound Synthesizer) عبر Web Audio API دون الحاجة لملفات صوت خارجية.
   - إشعارات منبثقة (Toasts) تنبهك بنتيجة كل عملية.
   - حفظ مستمر للبيانات في متصفحك عبر `localStorage` حتى تظل بياناتك وعملياتك محفوظة عند إعادة تحميل الصفحة.
   - زر لاستعادة البيانات التجريبية الافتراضية في أي وقت.

## 🚀 كيفية التشغيل

لا تحتاج إلى تثبيت أي مكتبات أو بيئة تشغيل (Node.js/Python غير إلزامية):

### الطريقة الأولى (الأسهل):
- ما عليك سوى فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome, Edge, Firefox, Safari).

### الطريقة الثانية (خادم محلي اختياري):
إذا كنت تفضل تشغيله عبر سيرفر محلي:
```powershell
python -m http.server 8000
```
ثم افتح الرابط في المتصفح:
`http://localhost:8000`
